## วัตถุประสงค์

## การติดตั้ง
ต้องใช้ Python 3.12 ขึ้นไป

```bash
git clone <URL ของ repository>
cd <ชื่อโฟลเดอร์>
```

## การใช้งาน

```bash
python main.py
```
